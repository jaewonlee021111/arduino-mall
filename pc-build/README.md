# BUILD LAB — 컴퓨터 부품 조회 & 견적 구성

제작: 이재원. HTML/CSS/JavaScript 기반 학습용 웹사이트입니다.

## 기능
- 8개 카테고리의 예시 부품 24개 검색 및 가격 정렬
- 카테고리별 부품 1개 선택, 교체 및 제거
- 용도별 예시 구성 3개, 목표 예산, 합계 계산
- CPU/메인보드 소켓, DDR 규격, 폼팩터, 쿨러 소켓 점검
- 단순 파워 여유 계산 (CPU+GPU+80W의 1.35배를 50W 단위로 올림)
- 견적 자동 저장, 클립보드 복사, Excel용 BOM 포함 CSV 다운로드
- 개별 부품 다나와 검색 링크
- 모바일 레이아웃

## 가격 및 호환성
표시 가격은 전부 연습용 예시이며 실제 최저가 또는 실시간 가격이 아닙니다. 실제 제품별 BIOS 지원, 커넥터, 물리적 크기, 라디에이터 공간은 구매 전에 제조사에서 확인해야 합니다. 파워 계산은 단순 참고식입니다. 배송비, 조립비, OS 비용은 합계에 포함하지 않습니다.

## 실행과 배포
`index.html`을 열거나 `python -m http.server 8000`을 실행합니다. Vercel에 이 폴더의 파일들을 업로드하면 빌드 없이 배포할 수 있습니다. 기존 아두이노 쇼핑몰과 별도 앱입니다.
